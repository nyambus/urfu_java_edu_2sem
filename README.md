Каждый каталог — отдельный Maven-проект; запускайте `mvn -q clean package` **внутри соответствующего каталога**, затем `java -jar target/*.jar` (для ЛР1 разверните WAR во внешнем Tomcat 11.0.26). Для Windows PowerShell подставьте конкретное имя JAR из `target/` и используйте `curl.exe -i` вместо `curl -i`. Требуются Maven 3.9.x и JDK 17 для ЛР2–7, JDK 21 для ЛР1. Запускайте ЛР2 и ЛР3 **по очереди**, поскольку обе слушают порт 8082; в ЛР4 два сервиса должны работать одновременно (8082 и 8084). ЛР6 и ЛР7 слушают 8080 и используют отдельные локальные базы.

## Отчёты

Установите `py -3 -m pip install 'python-docx>=1.1'`, затем `py -3 reports/build_reports.py`. Скрипт создаёт шесть **отдельных** `.docx` в `reports/`, используя неизменённые `reports/docx_builder.py` и эталонный `reports/Отчет_о_лабораторной_работе_13_Козионов.docx`. Файл `reports/figures.md` описывает, какие реальные кадры сделать и какие действия их производят. Заполнители `[СКРИНШОТ: ...]` не являются скриншотами; до сдачи замените их личными кадрами, а ожидаемые результаты в отчётах — фактическими. Для публикации выполните настройку собственного Git-репозитория и `git push` вручную; доступ к аккаунту GitHub здесь не подразумевается.

## Принятые допущения

- ЛР №1: выбран приложенный новый вариант A (чистый Spring MVC); старый вариант B не реализован. Вариант задания — `/uppercase`.
- ЛР №2: шапка указывает Spring Boot 3, конфигурация явно задаёт 2.7.16; взята конфигурация. Адрес обработчика на скриншоте нечитаем, выбран `POST /api/request`.
- ЛР №6: описание теории упоминает Spring Boot 2, но конфигурация проекта требует 3.1.5; выбрана 3.1.5. Поля таблицы «Учебные дисциплины» — название, преподаватель и число часов; API `/api/subjects`.
- ЛР №7: указанная в задании версия Spring Boot 3.1.15 отсутствует в Maven Central; применена доступная 3.1.12 (в задании разрешена другая версия). Для групп выбраны номер, факультет и курс; их маршруты указаны в README ЛР7.
- Динамические времена, ID и фактические журналы не фиксируются заранее. До выполнения каждого запроса результаты в отчётах — **ожидаемые**, не протокол испытаний.
